# SRAM Controller
Ana Isabel Guzmán 16863

La implementación en Logisim Evolution parte desde compuertas básicas hasta un sistema modular completo. Se diseñó un memory_cell que integra control de escritura mediante WE y active, lectura con RE, y direccionamiento usando un decoder. Las celdas se agrupan en una matriz y se conectan a un multiplexor de salida, permitiendo acceso eficiente a datos mediante señales Di, Do, WE, RE y ADDR. El diseño es funcional, escalable y validado mediante simulación directa en el entorno.
